# MF 行为合理性排查

日期：2026-10-31。结论：发现原始实现的冷启动分数会干扰首轮推荐；已在不修改作者源码的前提下建立并测试本地适配层。适配后的 MF 具备可验证的个性化学习信号，可作为本项目的模拟分析案例，但不是已经验证有效的现实推荐系统。旧案例数据不能与新配置混用。

## 排查方法

固定 500 用户、2000 物品、20 维 Dirichlet(0.5) 真实偏好与属性、20 步随机启动、100 步部署、不重复消费、不新增内容、无兴趣漂移。比较原始实现、明确冷启动策略的实现、持续训练与冻结模型。增加训练深度对照和一个四兴趣组的正向控制。指标直接检查模拟真实分数与推荐，而非把训练后参数变化当作学习有效的充分证据。

## 发现一 原版首轮推荐受到未训练物品支配

seed 123 启动后已训练覆盖 1971/2000 个物品，但首轮推荐列表中 99.96% 的位置来自尚未参与训练的物品。原版中这些物品保留随机潜在向量，与训练后物品的分数尺度不一致。少量未训练物品因此可以主导大量用户的列表。另一份此前保存的 seed 124 记录也有相同现象，比例约 78.38%。

原始算法源码保持未改动。本地适配类在每次拟合后，按 LensKit 返回的编号顺序写回已训练因子，并将未训练物品潜在向量设为零，明确赋予零预测分数。此策略只使用交互记录判断是否训练覆盖，不读取真实用户偏好来训练。零分是本项目采用并需披露的冷启动策略，不代表这些物品没有实际价值；它也不一定适用于其他分数范围或真实平台。

两次调整后的完整模拟中，未训练物品均未占据部署期推荐列表。原版结果应保留作诊断对照，正式案例重新生成并明确记录策略。

## 发现二 五次 ALS 迭代只适合运行检查

在完全相同的已记录启动数据上，分别拟合 5、20、40 次迭代。对同一个剩余内容池，按 MF 排序展示十条，再按本模拟的真实偏好选择最佳内容，平均分数分别约为 0.1060、0.1164、0.1182；随机展示十条后作相同选择的精确期望约为 0.0836。增加到 20 次明显改善早期表现，20 与 40 次在另一处快照上差别很小。但这不构成所有设置下的收敛证明。

之后使用冷启动适配、20 次迭代重跑两次完整持续训练案例，并运行一个冻结模型对照。调整后完整持续训练案例用时约 45.84 和 42.42 秒（同机、单线程配置）；冻结案例约 32.67 秒。没有保证其他规模、迭代数或机器的耗时。

## 发现三 模型有学习信号 但表现并非一直良好

- 调整后两次模拟，在未消费候选物品上的平均逐用户 Spearman 排序相关约为 0.20–0.26，而不是完全随机；这是有限的学习信号，不是很高的预测准确度。
- 在同一候选集合中，把学到的用户表示错配给其他用户会降低偏好匹配程度，说明个性化信息在起作用。
- seed 123 中，部署前 20 步的平均选择偏好分数约为 0.0927，冻结模型约为 0.0811。持续更新在这个阶段有帮助。
- 部署末 20 步两者分别约为 0.0607 和 0.0604。原始数据记录的随机参照末期约为 0.0797；该跨历史比较不能作为严格因果效应。
- 在同一份后期历史、同一个剩余内容池上重新拟合，增加到 40 次迭代仍未恢复早期水平。随机展示的同池期望优于该 MF 排序。因此，后期下降不能简单说成整个内容池已耗尽或仅因 ALS 迭代太少。

后期下降可能涉及隐式反馈目标、选择过程、已消费内容排除与推荐反馈等因素。本次没有识别其中的因果贡献，也不能直接称为信息茧房。模型不必处处优于随机才能用于诊断案例，但相关现象必须如实报告。

## 正向控制

建立 200 用户、400 物品、4 个明确兴趣组的简单数据。20 步随机启动、20 次 ALS 迭代后，推荐前十条中 99.95% 匹配用户的兴趣组；错配用户表示后为 0%。同一剩余内容池的随机期望约为 21.45%。这证明模型在容易学习的构造数据上可以恢复分组信号，不代表原始连续偏好场景同样容易，也不是项目研究发现。

## 对项目的决定

可以继续现有收紧方案：合成已知变化序列用于主要验证；明确标注设置的 MF 消费记录用于可视化诊断案例。正式模拟使用固定兼容环境和已披露的冷启动适配，20 次 ALS 迭代作为当前起点。不要把原始未处理版本产生的早期变化当作自然收缩，也不要承诺模型一定持续优于随机。

当前剩余工作是正式多种子实验、指标检查和案例解释，不是等待某个在线服务或无法获得的数据。两次运行与正向控制仍是有限审查，不是所有配置可靠性的保证。

## Update 可用表述

We verified execution and then audited model behavior. The audit found that randomly initialized scores for unseen items could dominate the first MF recommendations. We added a local adapter with an explicit zero-score policy for untrained items, leaving the upstream code unchanged, and reran two full configurations with 20 ALS iterations. The model showed personalization, although later preference matching remained limited. We will disclose these settings and use MF histories as diagnostic cases rather than assume that every decline reflects a filter bubble.
